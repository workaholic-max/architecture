# Section Comments

Section comments make the structure of a file with several distinct concerns visible at a glance.

Full reasoning and editor setup: [Dev Lab section comments](https://github.com/workaholic-max/dev-lab/tree/main/code-style/section-comments).

## Repository Adoption

Use dividers for real blocks such as types, state, lifecycle, handlers, and implementation. Do not add them to short,
single-purpose files or manufacture sections merely for consistency.

This is a readability preference, not an architectural boundary.
