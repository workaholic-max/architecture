# Documentation

These documents define portable workflows for applying the architecture. Read the
[`Architecture Guide`](../ARCHITECTURE.md) first; it decides ownership and dependencies, while these guides explain how
to make common changes.

Choose the guide that matches the work:

- Add a navigable product area: [Adding a Domain](new-domain.md)
- Add a reusable product capability: [Adding a Feature](new-feature.md)
- Add a runtime capability: [Adding a Service](new-service.md)
- Prepare any change for handoff: [Code Style and Verification](code-style.md)

The guides use placeholders rather than repository examples. They remain valid after the included demonstration code
is renamed or removed.
